## Título de la experiencia

Maquetación Estructurada y Presentación de Datos Tabulares con HTML5 y CSS.

## Contenido del laboratorio

| Archivo | Descripción |
|---|---|
| `tablas.html` | Tabla #1 — Informe de gastos de viaje, usando `<table>`, `<tr>`, `<td>` y relación de celdas con `headers`/`id`. |
| `tablas2.html` | Tabla #2 — Misma tabla estilizada con una hoja de estilos externa (clases `.tabla`, `.modo1`, `.modo2`). |
| `estilosTabla.css` | Estilos aplicados a `tablas2.html`. |
| `parrafos.html` | Ejemplo #3 — Párrafo con cita (`<q>`) y texto resaltado con `<strong>`, usando el selector descendiente `p strong`. |
| `estilosParrafos.css` | Estilos aplicados a `parrafos.html`. |
| `Ejemplo1.html` | Ejemplo #4 — Navegación web con enlace externo seguro (`target="_blank" rel="noopener"`), combinando selectores de clase e ID. |
| `EjemploSecciones.php` | Ejemplo #5 — Estructura semántica completa (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`). |
| `ValidacionesHTML5.html` | Ejemplo de validación de formularios con los pseudo-selectores `:required:invalid` y `:required:valid`. |
| `Laboratorio2.zip` | Todos los archivos del laboratorio comprimidos. |

## Temas cubiertos

- Configuración y metadatos del documento (`<head>`, `charset`, `viewport`).
- Elementos semánticos y estructurales de HTML5.
- Tablas HTML (`<table>`, `<tr>`, `<td>`).
- Hipervínculos y navegación segura.
- Selectores CSS: universal, tipo, clase, ID, descendiente e hijo directo.

## Cómo verlo

Clona el repositorio y abre los archivos `.html` directamente en el navegador.
El archivo `EjemploSecciones.php` requiere un servidor local con PHP (por ejemplo XAMPP) para que se muestre correctamente el año dinámico del pie de página.
